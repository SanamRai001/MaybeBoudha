When the file is added:

1. keep the filename `Boudha.STL`;
2. preserve the creator/source/license attribution in `docs/THIRD_PARTY_ASSETS.md`;
3. do not replace it with a file from a mirror unless the license/provenance can be verified;
4. run `/?model=licensed` to verify the imported geometry;
5. keep the procedural stupa as the failure fallback.

Normal `/` continues to use the procedural visual study until the imported model has been visually reviewed.
