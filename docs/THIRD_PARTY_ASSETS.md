# Third-Party Visual Assets

MaybeBoudha's application code and synthetic geometry are separate from third-party visual reference material.

## Phase 3P photographic surface reference

The synthetic Boudhanath visual feasibility study optionally uses a cropped view of this photograph as a surface reference for the harmika/eye and upper-spire materials:

- File: `20110725 Budha eyes closeup Bodhnath Stupa Kathmandu Nepal.jpg`
- Author: **Ggia**
- Source: Wikimedia Commons
- Source page: https://commons.wikimedia.org/wiki/File:20110725_Budha_eyes_closeup_Bodhnath_Stupa_Kathmandu_Nepal.jpg
- License: **Creative Commons Attribution-ShareAlike 3.0 Unported**
- License: https://creativecommons.org/licenses/by-sa/3.0/

The project does not claim ownership of that photograph.

### How it is used

The web prototype loads the Wikimedia-hosted preview at runtime and uses cropped texture coordinates on synthetic geometry.

If the remote image cannot load, the scene falls back to the fully procedural material.

No Boudhanath field-capture or scan data is included.

### Share-alike note

## MiniWorld3D model research

During Phase 3P research, a separate Boudhanath STL by MiniWorld3D was identified on Pinshape under **CC BY**.

That model is **not currently included in MaybeBoudha**.

If it is ever imported, its exact downloaded file, license evidence, author attribution, and any modifications must be recorded here before merging.
